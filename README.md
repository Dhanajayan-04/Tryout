# 🚀 Tryout – DSA Practice in C++

Welcome to **Tryout**, my personal repository for practicing Data Structures and Algorithms (DSA) using C++. This repository contains solutions to coding problems that help me strengthen my problem-solving skills, understand core programming concepts, and prepare for technical interviews.

## 📂 Repository Structure

```text
Tryout/
├── Arrays/
├── Basic-Maths/
├── Hashing/
├── Patterns/
├── .gitignore
└── README.md
```

### 📚 Topics Covered

- **Arrays** – Array manipulation, searching, sorting, and problem-solving techniques.
- **Basic Maths** – Mathematical operations, number-based problems, and fundamental algorithms.
- **Hashing** – Hash maps, hash sets, frequency counting, and efficient lookups.
- **Patterns** – Pattern-printing problems using loops and logical thinking.

## 🛠️ How to Use

1. Clone this repository:

   ```bash
   git clone https://github.com/Dhanajayan-04/Tryout.git
   ```

2. Navigate to the repository:

   ```bash
   cd Tryout
   ```

3. Open the topic folder you want to explore.

4. Compile and run a C++ program:

   ```bash
   g++ filename.cpp -o output
   ./output
   ```

   Replace `filename.cpp` with the name of the C++ source file you want to execute.
